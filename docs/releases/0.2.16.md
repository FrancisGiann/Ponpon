# Ponpon 0.2.16

Transfer entry now shows the source and destination wallets’ current balances, the balances after the transfer, and the total across active wallets. **Transfer all** fills the amount from the source wallet’s available balance. Editing an existing entry excludes its old posting from the available amount and projection. Transfers require two different wallets, a positive centavo amount, and enough recorded funds in the source wallet. The preview and save path use exact integer centavos and recheck the latest ledger snapshot before saving. Transfers remain manual ledger records; Ponpon never moves real money or charges a transfer fee.

Download **Ponpon-0.2.16-arm64.apk** for ARM64 Android 8.0+ (version code **2018**). The package `dev.giann.pocket_entry` and existing signing identity are preserved.
